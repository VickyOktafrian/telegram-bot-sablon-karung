# Template Google Sheet

File CSV di folder ini berisi **header kolom** dan **satu baris data contoh** (fiktif) untuk tiga tab: `User`, `Order`, dan `Detail Log`.

Tab `Ringkasan` berisi rumus, jadi dibuat manual. Lihat [../docs/google-sheet-schema.md](../docs/google-sheet-schema.md).

Ganti ID Telegram contoh (`111111111`, `222222222`) dengan ID asli sebelum dipakai.
